# ①課題名
Local Travelerアプリ（Memoアプリ応用）

## ②課題内容（どんな作品か）
- 旅行の計画と準備タスクを管理する Web アプリです。
- **複数の旅行を管理**：「台湾旅行」「オーロラ旅行」のように旅行ごとにデータを分けて保存し、ドロップダウンで切り替えられます。
- JSON形式のデータを持たせています。
### データ構造（LocalStorage）

キー `travelTrips` に、次の形の JSON を保存しています。

```json
{
  "currentTripId": "1700000000000",
  "trips": [
    {
      "id": "1700000000000",
      "destination": "台北・九份",
      "startDate": "2026-12-20",
      "endDate": "2026-12-25",
      "themeStyle": "theme-night-city",
      "destinationImagePath": "images/jiufen.jpg",
      "activities": ["夜市で食べ歩き", "十分でランタンを飛ばす"],
      "restaurants": ["鼎泰豊 信義本店", "阿宗麺線"],
      "shops": ["カルフール", "誠品書店"],
      "prepTasks": [
        {
          "id": "1700000000001",
          "taskName": "パスポートの有効期限確認",
          "dueDate": "2026-12-10",
          "isCompleted": false
        }
      ]
    }
  ]
}
```
- **背景テーマ**：リゾート・オーロラ・雪景色・和モダン（青海波）・桜・紅葉・京の夜など13種類から選べます。画像を使わず CSS だけで描いているため軽快です。
- **保存容量の表示**：LocalStorage の使用量の目安を画面の最下部に表示します。

## ⑤工夫した点・こだわった点
- 画像をLocal Strageに保存するとたくさん容量を消費してしまうので、パス（または画像URL）のみを保存するようにしました（ただしサブフォルダ（/imagesフォルダ）の中のファイルしか使えない）。
- スタイルについても、旅の行き先ごとに選べるようにしていますが、こちらも容量を抑えるために、スタイル指定のテキストのみをLocal Strageで保管する作りにしました
- Local Strageの容量もわかるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 画像ファイルは任意のパスで指定できるようにしたかったのですが、仕様上できなかったので、使い勝手が落ちてしまいました。
- このデータを元に、生成AIのAPIを使って、旅行の具体的なスケジュールを提案させるような機能を作りたいです。
