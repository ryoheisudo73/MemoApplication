# LocalTraveler

旅行の計画と準備タスクを管理する Web アプリです。
HTML・CSS・JavaScript だけで作られており、データはブラウザの **LocalStorage** に保存されます。サーバーやインストールは不要で、ページを再読み込みしたりブラウザを再起動したりしても、入力した内容は残ります。

## 主な機能

- **複数の旅行を管理**：「台湾旅行」「オーロラ旅行」のように旅行ごとにデータを分けて保存し、ドロップダウンで切り替えられます。
- **基本情報**：行き先・日程（出発日〜帰着日）・背景テーマ・行き先の画像を登録できます。
- **目的別リスト**：「そこでやりたいこと」「行きたいレストラン」「行きたいお店」を追加・削除できます。
- **事前準備タスク**：やることを期日付きで登録し、チェックボックスで完了を管理できます。
- **期日接近アラート**：未完了で期日が今日から3日以内のタスクがあると、画面上部に警告を表示します。
- **旅の年表**：登録済みの旅行を出発日順・年ごとに一覧表示します（折りたたみ可）。「あと○日」「旅行中」「旅行済み」の状態も表示されます。
- **背景テーマ**：リゾート・オーロラ・雪景色・和モダン（青海波）・桜・紅葉・京の夜など13種類から選べます。画像を使わず CSS だけで描いているため軽快です。
- **保存容量の表示**：LocalStorage の使用量の目安を画面の最下部に表示します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 行き先・日程・テーマなどを入力します。
3. 画面下の **「登録」** ボタンを押して保存します（登録済みの旅行では **「変更」** ボタンになります）。
   - 入力しただけでは保存されません。未保存の変更があるまま旅行を切り替えたりページを閉じたりすると、確認が表示されます。
4. 別の旅行を追加するときは **「＋ 新しい旅行」** を押します。

### 行き先の画像の指定方法

画像そのものは LocalStorage に保存せず、短いパスまたは URL だけを保存します。

| 方法 | 手順 | 保存される値 |
|---|---|---|
| ファイルを選択 | 画像をあらかじめ `images/` フォルダに入れ、「ファイルを選択」でその画像を選ぶ | `images/ファイル名` |
| URLで指定 | 「URLで指定」を押し、画像の URL を入力して Enter | 入力した URL |

> ブラウザのセキュリティ仕様により、選択したファイルのフルパスは取得できません。そのため「ファイルを選択」ではファイル名だけを使います。`images/` に画像が入っていない場合は、その旨のメッセージが表示されます。

## ファイル構成

```
.
├── index.html   # 画面の構造
├── style.css    # レイアウトと背景テーマ
├── app.js       # LocalStorage への保存・読み込みと画面の操作
└── images/      # 行き先の画像を置くフォルダ（中身は git の管理対象外）
```

`css/`・`js/`・`index_complete.html` は、元になったメモ帳テンプレートのファイルで、このアプリでは使用していません。

## データ構造（LocalStorage）

キー `travelTrips` に、次の形の JSON を保存しています。

```json
{
  "currentTripId": "1700000000000",
  "trips": [
    {
      "id": "1700000000000",
      "destination": "台北・九份",
      "startDate": "2026-12-20",
      "endDate": "2026-12-25",
      "themeStyle": "theme-night-city",
      "destinationImagePath": "images/jiufen.jpg",
      "activities": ["夜市で食べ歩き", "十分でランタンを飛ばす"],
      "restaurants": ["鼎泰豊 信義本店", "阿宗麺線"],
      "shops": ["カルフール", "誠品書店"],
      "prepTasks": [
        {
          "id": "1700000000001",
          "taskName": "パスポートの有効期限確認",
          "dueDate": "2026-12-10",
          "isCompleted": false
        }
      ]
    }
  ]
}
```

| キー | 内容 |
|---|---|
| `travelTrips` | 全旅行のデータと、最後に開いていた旅行の ID |
| `timelineOpen` | 旅の年表の開閉状態（`"true"` / `"false"`） |

旧バージョンのキー `travelData`（旅行1件のみの形式）が残っている場合は、起動時に `travelTrips` の1件目として自動的に引き継ぎます。

## 動作環境

Google Chrome・Safari・Edge・Firefox などの最新版のブラウザで動作します。

## 注意事項

- データは **使用しているブラウザの中だけ** に保存されます。別のブラウザや別のパソコンとは共有されません。また、ブラウザの閲覧データ（サイトデータ）を削除すると消えます。
- LocalStorage の容量はブラウザごとに約 5MB です。画像は LocalStorage に保存しないため、通常の使い方で上限に達することはほとんどありません。
